# Contributing

Thank you for taking the time to look at Trindle Icons.

The glyph batch files are long on purpose: each icon is data, one block per icon, and is not meant to be tidied into shorter code.

Code changes are not taken through this repository at the moment; the project is set up this way on purpose. If you have a bug or an idea, please report it on Buildmorphic or as a GitHub issue, whichever you prefer. Please include:

- what you did,
- what you expected to happen,
- what happened instead,
- the version of the icon theme and your desktop setup.

Security problems go through the private route in [SECURITY.md](SECURITY.md), not the public issue list.

You are free to fork the project under the licence in [LICENSE](LICENSE).

## Building and the version

The version number lives in the `VERSION` file only. See the README for the build steps.
