# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 1.4.x | Yes |
| Older | No |

## Reporting a problem

Report security problems privately through GitHub's private vulnerability reporting on this repository (the Security tab, then "Report a vulnerability"). If that is not available, email icons@trindle.org.

This is a small project run by a small team. We will reply as soon as we can, but we cannot promise a fixed time.
